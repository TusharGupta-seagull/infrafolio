# infrafolio

Personal portfolio.

Built with React, TypeScript, and Three.js. Designed to feel like a real product, not a template.

## Stack

| Layer | Technology |
|---|---|
| Framework | React 19 + TypeScript |
| Build | Vite 8 |
| 3D | Three.js via React Three Fiber + Drei |
| Animation | Framer Motion |
| Routing | React Router v7 |
| Icons | Lucide React, React Icons |
| Styling | Vanilla CSS with design tokens |

## Project Structure

```
src/
├── components/     # Reusable UI primitives (Typography, Button, Badge, Section, etc.)
├── sections/       # Page-level sections (Hero, Experience, Projects, Skills, etc.)
├── pages/          # Route-level page compositions
├── data/           # Content and structured data
├── hooks/          # Custom React hooks
├── lib/            # Utilities
└── styles/         # Shared styles
```

## Getting Started

```bash
# Install dependencies
npm install

# Start dev server
npm run dev

# Type-check and build
npm run build

# Preview production build
npm run preview
```
